Tentang Project

Project ini menganalisis ulasan pengguna aplikasi Mobile JKN yang dikumpulkan dari Google Play Store. Alur pengolahan data mencakup Exploratory Data Analysis (EDA), text preprocessing, pelabelan sentimen, pembobotan kata menggunakan TF-IDF Bigram, klasifikasi dengan machine learning, evaluasi model, serta visualisasi data secara interaktif.

Teknologi

Dibangun menggunakan workflow NLP dan machine learning berbasis Python.
